# Материалы для селлеров Яндекс Маркета

Сто редакционных разборов Pomonete с условными данными, проверяемыми расчётами и иллюстрациями. Все адреса в [списке публикаций](publications.md).

В `cases/` хранятся темы, текст и исходные числа для трёх сценариев каждой статьи. `build.py` собирает статические страницы, карты сайта и PNG-иллюстрации. Для сборки нужны Python 3.9+, Pillow и шрифт Arial или DejaVu Sans.

```sh
python3 build.py
python3 build.py --output /tmp/pomonete-preview
```

Первая команда проверяет число статей, длину основного текста, заголовки и совпадения фраз. Вторая собирает локальное превью. При публикации `--series` задаёт серии, `--base` задаёт канонический адрес.
